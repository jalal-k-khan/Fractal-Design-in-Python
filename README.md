# Visual Design Using Fractals - Lab 01

A visual design application generating recursive fractal patterns programmatically. Developed for **Design Lab 01** as part of the BS (Computer Science) program at SEECS, NUST.

## 📌 Project Overview

This project explores the mathematical principles of **self-similarity**, **recursion**, and **iteration** by generating custom visual fractal compositions programmatically
